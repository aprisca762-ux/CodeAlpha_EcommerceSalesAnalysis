# E-Commerce Sales Analysis

## Project Overview

This project was completed as part of my CodeAlpha Data Analytics Internship.

The project focuses on analyzing e-commerce sales data using Python to identify sales and profit patterns across products, categories, and regions.

## Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## Analysis Performed

- Data inspection and cleaning
- Duplicate detection and removal
- Sales and profit analysis
- Product performance analysis
- Category analysis
- Regional sales analysis
- Data visualization

## Key Findings

- Total Sales: ₦20,730
- Total Profit: ₦4,334
- Total Quantity Sold: 66
- Laptop recorded the highest product sales at ₦6,350.
- Mouse recorded the lowest product sales at ₦360.
- Electronics generated more sales than Accessories.
- 2 duplicate records were removed during data cleaning.

## Project Files

- `E-commerce sales analysis.ipynb` — Python analysis and visualizations
- `CodeAlpha_EcommerceSales.csv` — Dataset used for the analysis

## Conclusion

The analysis demonstrates how Python and data visualization can be used to clean, explore, and communicate insights from e-commerce sales data.
